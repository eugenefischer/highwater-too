# Bundled fonts

All under the SIL Open Font License 1.1 (licence texts beside them). The versions are the ones Highland 2 itself ships (in its app's Resources/Fonts), so text measures as in Highland's PDFs.

- Courier Prime 1.203 (OFL.txt): screenplay, manuscript and plain-text templates.
- Highland Sans 2.002 (HighlandSans-OFL.txt; Reserved Font Name "Highland Sans"): Treatment. Unmodified.
- Amiri 0.113 (Amiri-OFL.txt; no Reserved Font Name): Novel. Modified for size and for Latin text: subset to Latin ranges and punctuation (fontTools subset, all layout features kept), and the default script's layout features made the same as Latin's, so a run of only punctuation or digits (".", "1. ") takes the Latin glyphs.
- Lato 1.104 (Lato-OFL.txt; Reserved Font Name "Lato"): Article's headings, and the stand-in for Avenir Next and SF Pro Display. Unmodified.
- Merriweather 1.584 (Merriweather-OFL.txt; Reserved Font Name "Merriweather"): Article's table-of-contents numbers, and the stand-in for New York. Unmodified.
- Gelasio 1.008 (Gelasio-OFL.txt; no Reserved Font Name): the stand-in for Georgia (Article, Wiki), with the same character widths. Instanced from the variable font at weights 400 and 700 and subset to Latin ranges.
- Tinos 1.340 (Tinos-OFL.txt; no Reserved Font Name): the stand-in for Times New Roman (MLA Report), with the same character widths. Subset to Latin ranges.

Highland 2's other template fonts are not redistributable and are used only when installed: Georgia, Times New Roman and Avenir Next (macOS), SF Pro Display and New York (Apple; Highland 2 keeps copies inside its app, where Highwater Too finds them).
